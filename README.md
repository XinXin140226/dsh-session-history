# dsh-session-history

DSH 插件。把 DeepSeek 官方 App 导出的聊天包导入成 DSH 会话，也能把 DSH 会话导出成 Markdown 或 zip。

导入之后是真正的 DSH 会话，不是另一个阅读界面。侧栏能看到，能搜索，思考过程折叠在你熟悉的位置，可以接着往下聊。

## 装之前先看这几条

- 版本 0.1.0，能用在 0.2.2-rc.1 的 DSH 上。别的版本没试过。
- 手机和电脑用同一个包，代码是纯 JavaScript，没有原生模块，不需要编译。
- 界面长什么样我没法替你确认，需要你装完自己看一眼设置里那一页。
- 导入不可撤销。DSH 没有删除会话的接口，导错了只能一条条归档。第一次用建议先勾一个会话试试。

## 安装

把 `dist/dsh-session-history-0.1.0.tgz` 交给插件管理，或者直接把源码目录作为本地包安装。装完重启一次 DSH。

重启后在设置的导航里找「聊天记录迁移」。找不到的话，去插件设置里的标签页看，界面会自动退到能用的那个位置。

## 怎么用

**导入**

打开导入页，填导出包的路径。插件会扫一遍常见下载目录，扫到了直接点。

读清单只读索引，不碰正文，两万条以内是毫秒级。清单支持按标题搜索、分页、全选当前结果，也可以直接点「最近三十天」。

勾好之后点导入，任务在后台跑，你可以去干别的。侧栏底部会显示一条进度，鼠标悬停能看到具体数字。

中途取消不会白干，已经导完的保留，下次导入会跳过它们。

**导出**

导出页列出所有会话，可以搜索，可以只看导入进来的。勾选后导出，产物是一个 zip，每个会话一个 Markdown 文件，另附一份清单。

只勾一个会话时，会出现「下载这一个的 Markdown」，直接拿到单个文件，不用打包。

**设置**

六个开关，改完点保存，插件会重启一次让配置生效。

| 选项 | 默认 | 说明 |
|---|---|---|
| 导入的会话带联网搜索 | 开 | 关掉后用官方精简工具集，恢复对话时不带搜索 |
| 写入来源说明 | 开 | 在建对话开头加一行，讲清这段记录的来历 |
| 导入图片（实验性） | 关 | 见下 |
| 时间处理 | 保留原始时间 | 也可以改成导入时间 |
| 检索过程怎么显示 | 一行摘要 | 也可以带检索词，或者完全不显示 |
| 性能档位 | 自动 | 按设备定，导入时会按实测速度向下调 |

已经导入过的会话不受这些改动影响，它们把自己的预设记在日志里了。

## 关于图片

默认关着，可以在导入页临时打开。开了以后会把导出包里的截图取出来，压缩后再交给 DSH 的附件存储。

压缩规则：长边超过 2048 或文件超过 1.2 MB 才重新编码，保持原格式。压完反而更大的保留原图，实测平均省 35% 左右。

压缩过的图会另存一份原图到插件目录的 originals 下，看原图时读它。没压缩的图不重复存。

两处占用在设置页都能看到，也都能手动清：

- 看图缓存 ~/.dsh/cache/attachments，超过七天没清会在下次启动时自动清一次。
- 原图存档 ~/.dsh/plugin-data/dsh-session-history/originals，不会自动清，需要时手动清。

原图清掉不影响会话里的图片显示，只是不再提供原图。

## 导入之后会发生什么

- 你的提问、思考过程、最终回复按原始顺序还原，时间戳保留。
- 每轮一个 turn，助手的每条消息一个 step，这是 DSH 自己的结构。
- 联网检索的过程压成一行，例如「检索 2 次 · 打开 3 页：api.github.com 等」。嫌吵可以在设置里关掉。
- 附件如果不是图片，只留一个文件名占位。
- 用户 id、邮箱、手机号、第三方授权、头像链接、token 用量这些一概不读不写。
- 原始会话 id 只存在插件自己的映射表里，用来去重和续跑，不进会话内容。

## 性能

在 1992 个会话、220 MB 的包上实测：

| 项目 | 数字 |
|---|---|
| 打开清单 | 158 毫秒 |
| 单个会话解析加写入 | 约 90 毫秒 |
| 全量导入 | 约 3 分钟 |
| 导入后文本占用 | 30 到 45 MB |

内存峰值取决于最大的单个会话，跟整包大小无关，因为 zip 是随机读的。

## 自测

需要能解析到 `@deepseek-ai/cordis` 和 `@deepseek-ai/dsh-session-persistence-jsonl`（DSH 安装目录里自带）：

```
node scripts/selftest.mjs 3 /path/to/deepseek_data.zip
node scripts/test-import.mjs
node scripts/test-export.mjs
node scripts/test-routes.mjs
node scripts/test-client.mjs
node scripts/lint-copy.mjs
```

测试只写 /tmp 下的临时目录，不碰真实会话存储。

`scripts/lint-copy.mjs` 是文案检查，会拦下破折号和一批营销腔的词。改界面文案后跑一遍。

## 目录结构

```
index.js           Host 半边：服务、后台任务、路由
client.js          Client 半边：设置页与侧栏进度
lib/zip/           零依赖 zip 随机读取，支持 ZIP64
lib/deepseek/      导出包解析、图片提取
lib/map/           会话到 DSH 事件的映射，只发七种白名单事件
lib/plan/          导入与导出的执行器
lib/store/         幂等表、任务锁、进度
lib/report/        Markdown 渲染、zip 打包
lib/caps/          设备分档
locale/            中英文案
scripts/           测试与文案检查
docs/              方案与验证记录
```

## 已知问题

- 界面观感没做人工确认，侧栏进度条的位置和大小可能要调。
- 卸载插件后，已导入会话记录的预设会回退到默认，工具集可能变。会话本身不受影响。
- 极长会话（接近 3 MB）的渲染没单独测过。
- 只验过 0.2.2-rc.1，其他版本靠能力探测降级，没有实测。

## 制作说明

代码和文档由 AI 助手在 DSH 会话里写，用的是 deepseek-v4.1-flash 1017 模型。

文档描述和实际行为可能有偏差，仓库里的文件都是同一台机器上生成的产物。遇到说法和现象对不上的地方，以代码和运行结果为准。
