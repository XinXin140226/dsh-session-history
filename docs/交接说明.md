# 交接说明

这份文档写给接手这个项目的人或模型。看完应该能知道项目在哪、做到哪一步、还有哪些坑。

## 项目是什么

DSH 插件，名字 `dsh-session-history`，中文显示「聊天记录迁移」。

功能：把 DeepSeek 官方 App 导出的聊天包导入成真正的 DSH 会话，也能把 DSH 会话导出成 Markdown 加结构化数据。

仓库 `https://github.com/XinXin140226/dsh-session-history`，默认分支 `main`。

## 目录在哪

源码：`/root/Documents/deepseek-harness/default-workspace/dsh-session-history`

同步脚本：`/root/Documents/deepseek-harness/default-workspace/tools/sync-repo.mjs`

安装方式：插件管理里链接这个源码目录，profile 里是软链接，改完源码重启 DSH 即生效。

## 代码结构

```
index.js           Host 半边：服务、后台任务、路由注册
client.js          Client 半边：设置页、导入导出界面、侧栏进度
lib/zip/reader.mjs 零依赖 zip 随机读取，支持 ZIP64
lib/deepseek/      导出包解析、图片提取与压缩
lib/map/           会话到 DSH 事件的映射
lib/plan/          导入与导出执行器
lib/store/         幂等表、任务锁、进度、缓存、原图存档
lib/report/        Markdown 渲染、zip 打包、交换格式
lib/caps/          设备分档
lib/host/routes.mjs 全部 HTTP 路由
scripts/           测试与文案检查
docs/              文档
```

分层原则：`lib` 下的东西不认识 DSH，只处理数据，可以脱离 DSH 跑。`index.js` 负责把 DSH 的服务喂进去。

## 包类型与预设

导入时会判断包的来源，条目上带 `kind` 字段：官方包是 `deepseek`，本插件导出的包是 `exchange`。

预设由 `presetIdFor(kind)` 决定默认值：官方包 `minimal`，插件包按配置里的 `searchPreset`。两种包都允许通过导入参数 `presetId` 覆盖，不是强制。可选值白名单是 `dsh-session-history`、`minimal`、`standard`，在 `index.js` 的 `PRESETS` 里，路由和界面共用这份，界面按包类型给默认选中项。

## 没做完

- **聊天界面里点图片还是走 DSH 自带查看器**，不会打开我们存的原始图。原图只能通过接口或设置页明细看。
- **导出上限 300 个会话**，超过要分批。原因是现在整份内容攒在内存里打包。
- **导入的会话不能整体撤销**，DSH 没有删除会话的接口。
- **界面观感没做人工确认**，只在手机和一台电脑上看过布局，细节可能还要调。

## 关键约束

这些是踩过的坑，改代码时别踩回去。

**会话头**：`version` 必须是 4，`isSeeded` 必填布尔，`cwd` 给了就必须是绝对路径，`createdAt` 是非负安全整数。

**surface 事件**：`user/message`、`assistant/message`、`developer/message` 必须带 `surfaceOp: 'append'`。

**消息必填**：`user/message` 的 `data` 本身就是消息，要有非空 `id`、`role: 'user'`、`source.kind`、`content` 数组。`assistant/message` 要 `data.message.id`、`role`、`source` 里 `kind: 'model'` 加 `provider` 和 `model`、`content` 数组。

**生命周期**：`developer/message` 必须落在已打开的 turn 与 step 内，`turn` 至少是 1。`turn/end` 前不能有未关闭的 step。

**无损 JSON**：事件里任何 `undefined` 属性都会让校验失败。映射层有递归 `compact()` 兜底，别绕过它。

**seq**：从 0 开始连续，不能跳号。

**Cordis**：服务要用 `ctx.provide(name, value)`，直接赋值会被拒。取可选服务用 `ctx.get('x')`，别用 `ctx.connection` 这种直接属性访问，没声明注入会抛。

**Config 模式**：用 `@deepseek-ai/schemastery`，不是 zod。

**路由**：同一路径注册 GET 和 POST 会互相覆盖，要拆成两个路径。

**上传**：`requestBody: 'streaming'` 才能收大文件，Web 层上限 300 MB。

**重启**：改完 Host 代码必须重启 DSH，光刷新页面不够。

## 怎么发版

1. 改 `package.json` 的 `version`
2. `npm pack --pack-destination dist`，再算 SHA256 写进 `SHA256SUMS.txt`
3. `git add -A && git commit`
4. `node ../tools/sync-repo.mjs` 推源码
5. 用 GitHub API 建 release 并上传 `dist` 下的两个文件

用于上传的令牌在 `/root/.dsh/.dsh-gitdeck/auth.json`，是 Git 操作台那个插件存的。脚本只在进程内读，不打印。
