# 使用说明

写给第一次用这个插件的人。按你要做的事来找对应段落就行。

## 我要导入 DeepSeek 的聊天记录

**第一步，拿到导出包**

在 DeepSeek 官方 App 里找到导出聊天记录的入口，导出后会得到一个 zip。文件名通常是 `deepseek_data-日期.zip`，一两百 MB 都正常。

**第二步，打开插件**

DSH 里点侧栏的设置，左侧导航找「聊天记录迁移」。找不到就在插件设置里翻，有的版本会把它放在插件分组下。

**第三步，选文件**

进「导入」页。有两种方式：

一是把 zip 直接拖进那个虚线框，手机和电脑都支持，从中转站拖文件也行。

二是点「选择文件」，在系统文件选择器里找到这个 zip。

选完会自动读清单，几秒钟。清单出来之前不用点别的。

**第四步，挑会话**

清单按更新时间排，最新的在上面。可以：

- 在搜索框里打标题的一部分，快速过滤
- 点「全选」把当前搜索结果全勾上
- 手动一个个勾

每个会话下面显示消息条数和时间。

**第五步，点导入**

按钮上会显示「导入 N 个会话」。点了之后任务在后台跑，你可以干别的。

侧栏底部会出现一条进度，鼠标悬停能看到具体数字。想停就点「取消」，已经导完的会保留，下次导入会跳过它们。

**导入后用什么模式**

插件会先看这个包是谁导出的，两种都能选，只是默认值不同。

DeepSeek 官方导出的包，默认极简。想换成带联网搜索或标准，在清单下面点一下就行。

本插件自己导出的包，默认带联网搜索，同样可以改成极简或标准。

**导完去哪看**

侧栏的会话列表里，按工作区分组。导入的会话时间按原始时间保留，所以老会话可能排在下面，往上翻找。

## 我要把 DSH 的会话导出来

进「导出」页。列表显示所有会话的真实标题。

勾选想要的，点「导出选中的 N 个」。会打包成一个 zip，里面每个会话一个 Markdown 文件，另有一份结构化数据，可以再导回来。

只勾一个会话时，按钮旁边会出现「下载这一个的 Markdown」，直接拿单个文件。

一次最多导出 300 个会话。更多的分几次导。

## 导入的会话能不能接着聊

能。导入的是真正的 DSH 会话，跟平常新建的一样，可以继续提问。

默认带联网搜索工具。不想要的话在设置里关掉，之后的导入就不带搜索了。已经导入的会话不受影响，它们把自己的预设记在日志里。

## 图片怎么办

默认不导图片。在导入页勾上「同时导入图片」，或者在设置里改成默认开。

开了之后：

- 截图会被压缩，实测平均省 35% 左右
- 长边超过 2048 或文件超过 1.2 MB 才重新压缩，小图不动
- 压完反而更大的，保留原图
- 某一张失败只记一条警告，不影响其他图，也不影响文字导入

压缩过的图会另存一份原图，占用在设置页能看到，可以清。


## 分享导出文件

导出完成后按钮旁边会多一个「分享」。点了会调起系统分享面板，可以发到微信、QQ、邮箱、网盘，剩下的交给系统。

手机上没有分享面板时，会自动改成下载，不会卡住。


## 更新插件

设置页最上面有「插件更新」，显示当前版本。

点「检查更新」会去 GitHub 看有没有新版，只有这一步需要联网。发现有新版会出现「更新到新版」，点了自动下载并安装，装完提示重启 DSH。

不会自动重启。看到提示后自己重启一次，新版本才生效。

更新下载会先试 gh-proxy.com 的代理，不行换 ghfast.top，都不行再走 GitHub 官方地址。

当前如果是本地开发链接（源码目录直接挂上来的），更新会把它覆盖成打包版本，界面会先问你一次。
## 设置项都是什么意思

| 选项 | 默认 | 说明 |
|---|---|---|
| 导入的会话带联网搜索 | 开 | 关掉后用精简工具集，恢复对话时不带搜索 |
| 写入来源说明 | 开 | 在每轮对话开头加一行，讲清记录从哪来 |
| 导入图片 | 关 | 见上一节 |
| 时间处理 | 保留原始时间 | 也可以改成导入时间，这样都排在最上面 |
| 检索过程怎么显示 | 一行摘要 | 也可以带检索词，或者完全不显示 |
| 性能档位 | 自动 | 按设备核数和内存定，导入时按实测速度往下调 |

改完点保存，插件会重启一次让配置生效。

## 占空间吗，怎么清理

导入的文字大概 30 到 45 MB（全量 1992 个会话）。

图片另算，看你导多少。

设置页底部有两处占用：

- **看图缓存**：`~/.dsh/cache/attachments`，超过七天没清会在下次启动时自动清
- **原图存档**：插件目录下的 `originals`，不会自动清，需要手动清

清掉原图不影响会话里的图片显示，只是不再提供原图。

## 导入后悔了能撤销吗

不能整体撤销。DSH 没有删除会话的接口，只能一条条归档。

所以第一次用建议先勾一两个试试，看效果满意再全量导。

## 出问题怎么排查

**提示「没有选文件」**：文件没选上，重新点「选择文件」。

**提示「选的文件不是 zip」**：选错文件了，选那个 `deepseek_data-日期.zip`。

**提示「找不到这个文件」**：路径失效了，重新选一次。

**提示「这个包里没有 chat_session_index.json」**：这个 zip 不是 DeepSeek 的聊天导出包。可能是别的软件导出的，或者你把这个插件自己导出的包又选进来了。

**提示「已有任务在跑」**：上一个导入还没结束，等它完或者点取消。

**导入完侧栏找不到**：导入的会话按原始时间排序，往列表下面翻。也可能落在别的工作区分组里。

**界面没变化**：装完新版本要重启一次 DSH，Host 那边的代码只有重启才会换。浏览器页面也要刷新。
